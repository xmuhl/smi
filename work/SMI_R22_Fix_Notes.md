# SMI R22 修复说明（R22-DEF-01：种子池无条件占位缺陷）

## 1. 缺陷来源

R20 收敛后的人工验收（2026-08-22）发现：主赛道每日监测表在**所有日期**都显示同样
四个板块（高股息中特估/电力/医药生物/半导体AI算力）。用户原始要求为"按范本
《A股收盘全景_20260717.xlsx》对每日主赛道板块的判定条件逐日筛选"，而这些板块
并非逐日计算所得。

## 2. 根因（规格层缺陷，非实现层）

- `config/tracks.yaml` 的 `tracks:` 列表 = 范本 07-17 当天的四个板块，v1 起作为
  **静态种子池**；`collect_tracks()` 每日无条件追加（`selectionReason: "seed"`），
  从不参与入池/出池判定。
- v4（R13-P2-01）为动态候选建立了入池/出池迟滞状态机，但种子被设计为
  永久豁免（文档化设计："无当日 universe 记录 → 退化为纯种子"）。
- 实证：08-20/08-21 电力近5日成交额排名 24、医药生物 19（范本阈值"全市场前5"、
  出池阈值 12），仍占据监测表——不可能由筛选条件导出。
- 范本自证逐日筛选语义：其"历史数据跟踪"区 07-16 核心主赛道="无"、
  07-17 核心=高股息/电力且**新增**银行/石油石化，板块集每日随条件变化。

## 3. 为什么历轮评审（含 ChatGPT 送审）未发现（流程检讨）

1. 缺陷在规格而非实现：种子永久豁免是文档化设计，历轮评审均为
   "实现对不对"的符合性审查，无人被要求回答"设计本身对不对"。
2. 送审提问结构收窄：逐轮围绕 NOT_CLOSED 编号收敛，不重开规格已答的问题。
3. 自动化验收验证内部一致性（决策⇄指标⇄状态机自洽），无"板块集合独立
   重算"的真理源断言；跨日板块集零变化从未被编码为告警。
4. 人工验收翻日对比才显形——这正是本次发现路径。

## 4. 修复内容（configVersion 3.2 → 3.3）

代码（collector/modules/tracks.py，e0c0db6）：
1. **种子并入状态机**：种子映射 universe 板块名后作为状态机**初始在池成员**
   （承继资格，grandfather 参数），此后与动态成员同规则出池；
2. **出池改仅排名口径**：连续 exitConfirmDays(2) 日排名跌出 exitRankMax(12)
   才出池；**净流入不再是出局条件**（范本 07-17 医药生物 -386.52 亿、半导体
   -730.77 亿仍在监测表=退潮主线/主跌浪，自证"成交额排名决定谁被监测，
   资金流决定评级好坏"）；净流入保留为入池门槛与评分维度；
3. **无数据日空池**：无 universe 归档日不再回退种子占位（fail-closed 空 items +
   UNAVAILABLE/TRACKS_INSUFFICIENT）；当日快照不过完整性门禁（部分响应日，
   如 08-18/19）同样不输出任何池成员；
4. tracks.yaml configVersion 3.3 / effectiveFrom 2026-07-20；
   tracksVersionSchedule：历史白名单 +3.3，cutoff(≥08-21) minConfigVersion
   3.2→3.3（版本门禁倒逼重生成，防止 3.2 存量伪装合规）。

辅助：

  历史保护（语义修订整体替换路径；默认行为不变，附正反测试）。背景：首轮
  25 天重生成中 08-20/21 的旧 3.2 PARTIAL tracks 被保护性保留。

  的回退假排名掩盖该缺口（表观 rank 1/3，实为 4~7 个受监测板块的内部互排，
  并非全市场排名）。现 fail-closed 剔除并以 module errors 条目
  `seed_unmapped_in_industry_universe:<id>(<名>)` 显式披露，杜绝静默消失。
  概念板块源接入列为已知边界/后续增强（同 sentiment/fundFlow 边界族）。

## 5. 假设清单（新增送审节：请评审者挑战假设而非仅核对实现）

历轮从未被重新验证的设计决策，现逐一列出，请评估是否仍成立：
- A1 迟滞双阈值（入池 poolSize=8 / 出池 exitRankMax=12）相对范本"前5"更宽松，
  理由是防 8/9 名抖动——是否过于宽松？
- A2 入池门槛保留"当日净流入为正"（requirePositiveInflow）——范本入选口径
  仅成交额排名，此门槛是否会导致缩量上涨的主赛道板块漏选？
- A3 minUniverseBoards=45（90 板块快照之半）+ 前向峰值×0.5 完整性门禁——
  对未来板块数变化（THS 扩容/缩容）是否足够鲁棒？
- A4 无数据日空池（而非展示占位）——符合验收决议，但前端"暂无赛道数据"
  提示是否足够传达"上游无快照、非市场无主线"？
- A5 种子映射失败（universe 从未出现该板块名）即移除——映射表由
  tracks.yaml 名称与 THS 板块名约定，是否存在别名漂移风险？
  **（已成现实：高股息中特估=概念板块不在行业口径，本轮按 fail-closed
  剔除+errors 披露处置；请评估该处置与概念板块源增强的优先级）**
