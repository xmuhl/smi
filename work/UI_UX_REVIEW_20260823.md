# SMI 网页版面设计评审与改进建议（2026-08-23）

> 性质：**设计评审 + 改进提案**，本文档不含任何已实施的代码改动。所有建议均为展示层，不触碰数据契约与 fail-closed 语义；涉及验收标准 displayRules 的条目已逐条标注。
> 证据基础：生产站 08-21（最新日）整页 6 屏截图、07-20/07-17 空态对照、App.vue/styles.css/9 个面板组件源码、template-standard.json displayRules。

## 一、现状盘点

### 信息架构（单页长滚动，4 分区）

```
sticky 头部：logo + 日期导航(◀/下拉/最新/▶) + 模块状态汇总 + 三指针日期
① 市场总览    ：宽基指数(8) 全宽 ＋ 两市成交额 / 市场情绪 (2列)
② 板块与资金  ：板块行情 / 主力资金流向 / 北向资金 (3等列)
③ 杠杆与主赛道：两融数据 ＋ 主赛道每日监测 (宽表)
④ 今日结论    ：规则引擎摘要（8 段结论条目）
```

### 设计 token 现状

- 色彩：bg #0f1115 / panel #171a21 / border #2a2f3a / 红涨 #ef5350 / 绿跌 #26a69a / 黄 #ffca28 / 蓝 #42a5f5——**A股红涨绿跌惯例正确**，深色对比度充足；
- 字体：系统中文栈（PingFang/雅黑），基准 14px，卡片标题仅 15px——**字号层级偏弱**；
- 布局：max-width 1440px；响应式 4列→2列(≤1199)→1列(≤767)；sticky 头部（毛玻璃）已有；
- 空态：诚实缺列文案体系完整（UNAVAILABLE/空池两分支），是本站特色优点。

## 二、问题清单（按严重度）

### P0-1 真 bug：模板字符串未插值（已在线上）

主力资金面板页脚显示字面量 `单位：${module.unit || "亿元"}`。位置 FundFlowPanel.vue:35，把插值写成了纯文本。一行修复，零风险。

### P1-1 三等列被北向持仓表撑爆 → 两大屏空白（最严重版面问题）

②区 grid-3 三列等高：北向资金面板内「季度持仓 20 行表」（每行含长英文名，行高很大）把整行拉到 ~2500px，而左/中列内容只有 ~600px——**截图实证 08-21 第 3~4 屏左侧近乎全空**。这是用户滚动体验的最大伤害点。

### P1-2 北向季度持仓信息价值/占屏比失衡

4308 只 → 仅展示前 20 条，point-in-time 参考数据（2026-06-30）却占据 ~2.5 屏高度。低频参考数据不应占据黄金滚动路径。

### P2-1 「今日结论」沉底

规则引擎摘要（④区）是每日阅读的**最高价值结论**，却排在 4000px 长页最底部。快速阅读者需要滚到底才能拿到结论。

### P2-2 无分区锚点导航

4 个分区 6 屏长页，sticky 头部只有日期导航，没有「总览/板块资金/杠杆赛道/今日结论」跳转 chip。

### P3-1 「✓已更新」徽标重复

每个卡片右上角都有，而头部状态行已汇总「7 FINAL·1 PENDING·1 PARTIAL」——非 FINAL 状态才有信息量，FINAL 的 ✓ 是噪音。

### P3-2 字号/间距无 scale

标题 15px vs 正文 14px 层级弱；间距 8/10/12/14/16/24 混用，无 4px 基数 scale；大数字（指数/成交额）无 tabular-nums，多卡片并排时位数跳动。

## 三、改进方案（三档，均不动数据契约）

### A 档：零风险快赢（建议立即做）

| # | 改动 | 文件 | 验收影响 |
|---|---|---|---|
| A1 | 修 `${module.unit}` 插值 bug | FundFlowPanel.vue:35 | 无（纯文本修复） |
| A2 | 北向季度持仓默认**收起**：显示前 5 行 + 「展开全部 20 条」按钮（展开状态记住到 localStorage） | NorthboundPanel.vue | displayRules 未强制展开渲染，需在 standard notes 补一句（见 C2） |
| A3 | 「✓已更新」徽标仅 status≠FINAL 时渲染（PENDING/PARTIAL 换黄色/蓝色提示点） | 各 Panel 公共 StatusBadge | 无 |
| A4 | sticky 头部加 4 个分区锚点 chip（①总览/②板块资金/③杠杆赛道/④结论），scrollIntoView + URL hash | App.vue + styles.css | 无 |

### B 档：布局重构（纯展示层，建议下一迭代）

| # | 改动 | 理由 | 验收影响 |
|---|---|---|---|
| B1 | ②区解除三等列：板块行情+主力资金保持 2 列，**北向资金改为独立全宽折叠卡**（默认折叠，只留一行摘要：模式/季度持仓日期/条数） | 根治 P1-1/P1-2；北向是低频参考数据，不配黄金位 | 需同步 displayRules「必须提供行业/概念/个股三 Tab」措辞→改为「面板内提供」 |
| B2 | 「今日结论」**双入口**：顶部 sticky 头部下新增一行「今日结论速览」（风险提示+市场环境两句，点击锚到 ④完整版），④区保持完整 | 结论前置不破坏既有 ④ 区（displayRules 对 summary 段落渲染要求不变） | 需在 displayRules 增补「允许顶部速览条」一句 |
| B3 | 主赛道宽表横向滚动优化：首列（板块名+定位）sticky 左固定，覆盖 76.4% 等长文案移到表格上方状态条 | 13 列宽表现在需要横向滚动且无冻结列 | 无 |

### C 档：视觉系统打磨（可选，统一 token）

```
字号 scale：12(辅助) / 13(正文次) / 14(正文) / 15→16(卡题) / 20(分区题) / 28(大数字)
间距 scale：4 / 8 / 12 / 16 / 24（替换现混用的 10/14）
大数字：font-variant-numeric: tabular-nums；指数/成交额统一 28px/600
状态色语义化：--ok(绿点)/--warn(黄)/--info(蓝)/--err(红)，替代文字徽标噪音
骨架屏：加载中用 skeleton 卡片替代单行「加载中…」
对比度复核：text-dim #9aa3b2 on #171a21 = 5.5:1 ✅；黄 #ffca28 仅作强调不过量
```

### 明确不做（保护稳定基线）

- 不动 9 模块数据契约、字段名、fail-closed 文案语义；
- 不引入图表/组件库大依赖（保持零依赖轻量前端）；
- 不改 A 股红涨绿跌配色与深色主题基调；
- 不做需要回填历史数据的任何展示（如 tracks 历史曲线）。

## 四、实施顺序建议

1. **A1 立即**（bug）；2. A2+A3+A4 一个 PR（一个部署）；3. B1+B2 一个 PR（需先改 standard displayRules 两处措辞，随 PR 同步提交）；4. C 档视验收节奏穿插。

每步部署后用 page_check.js 探针 + 抽一日截图对照，保证「功能不变、版面升级」。
